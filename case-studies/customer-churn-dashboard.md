# Customer churn dashboard

## Project overview

This practice project was completed through DataCamp's *Customer Churn Project*. The goal was to build a clear Power BI dashboard for exploring customer churn and identifying the main patterns behind customer departures.

## What I built

I designed and built the complete dashboard, including its layout and visualisations. The report brings the main customer and churn measures together in a single overview.

## Dashboard highlights

The dashboard shows:

- a 26.86% churn rate
- 6,687 customers and 1,796 churned customers
- churn categories and reasons
- customer counts by contract type
- churn rates by US state
