# Data analytics case studies

This portfolio presents two Power BI dashboard projects: a customer churn analysis and a mining operations analysis.

## 1. Customer churn dashboard

This practice project was completed through DataCamp's *Customer Churn Project*. I designed and built the dashboard to explore customer churn, including churn rates, customer segments, contract types, churn reasons and geographic patterns across the United States.

## 2. Mining operations dashboard

This personal project demonstrates an end-to-end analytics workflow using synthetic mining data. I generated the data, organised it into bronze, silver and gold layers in Snowflake, and created a Power BI dashboard to monitor production, equipment utilisation, operating hours, overdue work orders and fuel efficiency.

All figures in this project are synthetic and do not represent a real mine or company.
